# WebUI 开发边界

> 本文规定 WebUI 修改的审查范围。数据库功能、数据正确性和事务一致性按各自模块的公共契约验证。

## 目录

---

## 界面修改

HTML、CSS 和前端交互修改采用代码审查与必要的语法检查，重点检查请求参数、错误处理、状态归属和用户数据的读写。

同一边界适用于 CLI 的 TUI 和 REPL 界面。CLI 验收覆盖命令、参数、JSON／CSV 数据、错误与数据库生命周期。Server 的 HTTP 套件直接验证数据、事务与传输契约。

> **禁止事项**：禁止编写、新增或执行 UI/UX、样式、布局、视觉基线、动画、开屏时间及其他界面耗时测试；禁止将其作为本地、CI、合并或发布门禁，也禁止改称冒烟、行为、诊断或可选手动检查继续执行。

---

## 数据库契约

数据库行为发生变化时，在对应的 Core、SDK 或 Server 模块验证数据内容、事务原子性、并发冲突及资源释放。沿用已有有效用例，新增用例围绕明确的功能需求或故障修复。

执行范围见[测试实践](testing.md)和 [Server 文档](server.md#按需开发自测)。页面文案、控件位置和源码排版由代码审查处理。
