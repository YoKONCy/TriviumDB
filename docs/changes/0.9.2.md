## 中文说明

`0.9.2` 是正式版。Rust crate、CLI、Server 源码、npm 和 Python 元数据统一使用 `0.9.2`。Git Tag 为 `v0.9.2`，npm 使用 `latest` 通道，Python 支持 3.9–3.12。Server 和 WebUI 继续采用 nightly 开发通道。

```bash
cargo add triviumdb@0.9.2
pip install "triviumdb==0.9.2"
npm install triviumdb@0.9.2
```

### 文件格式、备份与迁移

- 内核采用主格式 15、WAL 7、文档结构 2 和统一 `.idx` 容器。容器绑定数据库与检查点身份，集中保存 QuIVer、已登记正文与关键词、属性索引、图目录和可选压缩重排组件。已完成提交的文件组损坏时保留恢复材料，以结构化错误拒绝不完整打开。
- Mmap 检查点对 generation 化 Payload 记录 SHA-256。快照和代际清单对每个制品记录长度、CRC32 与 SHA-256。等长且内部 CRC 有效的 Payload 串档会被拒绝。快照验证和恢复使用同一目录准入规则，发布时原子拒绝同名目标，清单与检查点元数据读取有大小上限。
- 既有 53 字节检查点标记与旧快照清单可读取。新的 Mmap 检查点写入 81 字节标记。旧快照按原摘要校验，旧 Payload CRC32 无法区分同尺寸的有效文件。完整备份、目录恢复和检查点条件见[快照与恢复](../lifecycle-snapshots.md)。
- 旧数据库格式通过外部迁移处理。独立工具支持主格式 5–15、三种 dtype 与 Rom/Mmap，在来源副本恢复并核对向量位模式、Payload、边、登记文本、索引、文档、命名图与回执。目标是新目录，之后直接打开其中的 `database.tdb`。维度迁移同时保留唯一约束、常规属性索引、登记正文与关键词，以及节点 ID 分配高水位。
- 回收旧代际按目录身份核对当前代与 Reader 租约。WAL 在事务首帧前检查全部记录的完整编码长度，与恢复共用 256 MiB 单帧上限。旧删除记录重放保留检查点已发布的新文档和文本，同步恢复后新增向量的检索可见性。

```bash
cargo build --locked --manifest-path crates/triviumdb-migrate/Cargo.toml --target-dir target/migration
python scripts/migrate.py --source /data/old.tdb --destination /data/current --check
python scripts/migrate.py --source /data/old.tdb --destination /data/current --execute
```

> **升级提醒**　停止来源持有者并保留完整文件组备份。旧内核环境使用升级前的备份。来源条件、可用磁盘和中断重试见[外部迁移指南](../migration.md)。

### 检索、文档与图查询

- Rust、Python 和 Node 检索默认阈值统一为 `0.0`。Rust `SearchConfig::with_exact(true)`、Python `exact=True` 和 Node `exact` 统一选择精确向量召回，并保留过滤、Top-K、后续处理与稳定同分排序。随机合成向量和手工特征可使用精确检索，语义 embedding 的 ANN 使用条件见 [QuIVer 指南](../quiver.md)。
- QuIVer 正式构图入口为 `batch_build`，SM 查询使用 `SmIndex`，冷热压缩运行时统一为 `QuiverRuntime`。既有中心化 INT8／INT4、查询精度和缓存配置继续由正式接口提供。TSNG 和对照构图归入研究快照，`EXPLAIN` 使用 `vector_access_path`。支持范围见 [SDK 正式接口清单](../sdk-contract.md)。
- 混合检索按 `alpha` 和 `1 - alpha` 加权倒数排名。权重为 1 时使用原始向量分数，权重为 0 时仅召回文本，范围外的权重会被拒绝。Payload 预过滤校对完整 JSON 值，保留 null、容器和正负零匹配。Hook 传回的向量在转成存储 dtype 后再次检查，Node Hook 拒绝 Promise 和非法命中，重排返回 null 时保留现有结果。
- 归档文档在重开后支持上下文和原文证据读取，展开前计入块候选预算。单次解析接入在写入前检查节点冲突，失败后清理仍待提交的候选。显式分批上传保留续传入口。Markdown 引用内的 HTML 提取保留真实来源范围并过滤隐藏文本。
- TQL 裸列与别名排序使用一致的投影规则，超出浮点索引精度的整数先按原值排序再分页。命名图查询遵守图作用域，零跳匹配保留有效的自身关系。加权最短路和 Yen 累计整个算子的实扫边预算，最短路以前驱记录保存路径前缀。可达性按筛选前的实际边读取计量，全路径查询区分查询深度与预算耗尽。
- 聚合和图算子保留可表示的浮点结果，覆盖 `SUM`、`AVG`、边权均值和路径乘积的溢出及抵消边界。SCC 保留完整无符号 ID，DPP 避免重复选点，NMF 与调和中心性保持有限结果。

### 接口、并发与命令行

- 持久化与恢复保留 binary64 精度及整数位模式。Node 的 `u64` 向量读取在数值无法无损转换为 `number` 时返回 `TDB_INVALID_INPUT` 和分量位置。Python 与 Node 返回原始边权的精确扩展值，CAS 按完整结构中的精确数值比较。Python `index_info()` 存根返回索引描述列表，Node CommonJS 与 ESM 使用同一组命名导出。
- HTTP 支持用十进制字符串写入、批量读取和投影大 ID。空查询结果保留已知列名，诊断位置按提交前的原始 UTF-8 文本计算。Prepared 缓存容量为零时返回 `TDB_PREPARED_DISABLED`。
- Server 将断连与期限传到读取、搜索及 TQL 写入的内核检查点。索引建议在同一次受控读任务内获取。节点和边删除后回收版本条目，旧 ETag 触发冲突。普通 JSON 响应在编码期间实施 16 MiB 上限。
- CLI JSONL 保留 `u64` 向量、自动分配的节点 ID 及边元数据。导入对整批节点和边保持原子性，导出拒绝覆盖源库制品或其别名。写事务已提交而检查点失败时，`write` 报告 `publish/committed`，`details.checkpoint_write` 记录可用的检查点结果。

### File formats, backups, and migration

- The engine uses main format 15, WAL 7, document schema 2, and a unified `.idx` container. The container binds to the database and checkpoint identities and stores QuIVer, registered text and keywords, property indexes, graph directories, and optional compressed reranking. Corrupt committed file groups preserve the recovery materials and fail with a structured error.
- Mmap checkpoints record SHA-256 for the generation-scoped Payload. Snapshot and generation manifests record each artifact's length, CRC32, and SHA-256. These digests catch a foreign Payload of the same length with a valid internal CRC. Verification and restore apply identical source directory rules. Publication atomically rejects existing targets, and manifest and checkpoint metadata reads have size limits.
- Existing 53-byte checkpoint markers and older snapshot manifests remain readable. A new Mmap checkpoint writes an 81-byte marker. Older snapshots are checked against their original digests. Their Payload CRC32 cannot distinguish two valid files of the same length. See [snapshots and recovery](../lifecycle-snapshots.md).
- An external tool handles database format upgrades. It supports main formats 5–15, all three dtypes, and Rom/Mmap. It recovers a source copy and compares vector bit patterns, Payloads, edges, registered text, indexes, documents, named graphs, and receipts. Open `database.tdb` directly in the new destination after migration. SDK dimension migration also preserves unique constraints, ordinary property indexes, registered text and keywords, and the node ID high-water mark.
- Generation reclamation checks the current generation and Reader leases by directory identity. WAL admission checks every encoded record before writing the first transaction frame and shares the 256 MiB frame limit with recovery. Replay of an older deletion preserves newly checkpointed documents and text. Recovered vector inserts become visible to indexed search.

```bash
cargo build --locked --manifest-path crates/triviumdb-migrate/Cargo.toml --target-dir target/migration
python scripts/migrate.py --source /data/old.tdb --destination /data/current --check
python scripts/migrate.py --source /data/old.tdb --destination /data/current --execute
```

> **Upgrade note.** Stop processes holding the source and back up its complete file group. Use the pre-upgrade backup with older engines. See the [migration guide](../migration.md) for source requirements, disk capacity, and interrupted-run recovery.

### Retrieval, documents, and graph queries

- Rust, Python, and Node share a default retrieval threshold of `0.0`. Rust `SearchConfig::with_exact(true)`, Python `exact=True`, and Node `exact` all select exact vector recall and retain filtering, Top-K, configured post-processing, and stable ties. Use exact search for random synthetic vectors and handcrafted features. The [QuIVer guide](../quiver.md) describes the evaluated semantic embedding workloads.
- The production QuIVer build entry is `batch_build`, SM querying uses `SmIndex`, and compressed residency uses `QuiverRuntime`. Centered INT8/INT4, query precision, and cache configuration remain available through the supported APIs. TSNG and experimental builds live in research snapshots. `EXPLAIN` reports `vector_access_path`. See the [SDK inventory](../sdk-contract.md).
- Hybrid retrieval uses reciprocal ranks weighted by `alpha` and `1 - alpha`. At 1 it returns raw vector scores. At 0 it retrieves only text. Out-of-range weights are rejected. Payload prefiltering preserves matches for null, containers, and signed zero. Hook vectors are validated after storage dtype conversion. Node Hooks reject Promises and malformed hits, and a null rerank result retains the existing hits.
- Archived documents can return context and source evidence after reopen, with block candidates charged before expansion. One-shot ingestion checks node conflicts before writing and discards a still-pending candidate after failure. Explicit staged uploads remain resumable. Markdown HTML inside block quotes preserves actual source ranges and filters hidden content.
- TQL resolves bare and aliased sort columns consistently. Integers outside index-key precision sort by the original value before pagination. Named-graph queries honor graph scope, and zero-hop matching retains valid self relationships. Weighted shortest paths and Yen share the actual edge-scan budget across the operator. Shortest-path prefixes use predecessor records. Reachability charges scans before filtering, and all-paths queries distinguish requested depth from budget exhaustion.
- Aggregates and graph operators preserve representable floating-point results for `SUM`, `AVG`, average edge weights, and path products. SCC retains complete unsigned IDs, DPP avoids duplicate picks, and NMF and harmonic centrality return finite results for the hardened cases.

### Interfaces, concurrency, and CLI

- Persistence and recovery preserve binary64 precision and integer bit patterns. Node rejects any `u64` vector component that cannot round-trip through a JavaScript number and identifies its position. Python and Node widen stored edge weights without rounding. CAS compares exact numbers throughout the JSON structure. Python `index_info()` types describe a list. Node CommonJS and ESM expose the same named exports.
- HTTP accepts decimal-string IDs for writes and batch retrieval and preserves large integers in projections. Empty queries retain known column names. Diagnostics refer to the originally submitted UTF-8 text. A zero-capacity Prepared cache returns `TDB_PREPARED_DISABLED`.
- Server propagates disconnects and deadlines through read, search, and TQL write checkpoints. Index advice is collected during the controlled read. Deletion reclaims node and edge version entries and stale ETags conflict. Ordinary JSON encoding enforces its 16 MiB response cap while serializing.
- CLI JSONL preserves `u64` vectors, edges attached to automatically assigned IDs, and edge metadata. Import applies the node and edge batch atomically. Export protects source artifacts and aliases from overwrite. A checkpoint failure after commit reports `publish/committed` in `write` and preserves available checkpoint status in `details.checkpoint_write`.
